# AI Layer Configuration

This directory contains the AI service configurations and integration logic.

## Features

### 1. Landing Page Generation
- AI-powered landing page content generation
- Multiple templates and styles
- SEO optimization

### 2. AI Sales Chatbot
- Natural language understanding
- Context-aware responses
- Multi-language support
- Integration with product catalog

### 3. Ad Campaign Generator
- Platform-specific ad content
- A/B testing suggestions
- Performance optimization

### 4. Product Descriptions
- SEO-friendly product descriptions
- Feature and benefit highlighting
- Multiple tone options

## Integration

The AI layer integrates with:
- OpenAI GPT-4 for content generation
- Custom prompts and templates
- Backend API for data access
- Real-time chat via WebSockets

## Configuration

Set the following environment variables:

```
OPENAI_API_KEY=your-api-key
```

## Usage

See the backend `ai.service.ts` for implementation details.
