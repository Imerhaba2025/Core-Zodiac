🚀 Getting Started
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Quick Start (Docker):
  docker-compose up -d

Manual Setup:
  ./setup.sh
  cd backend && npx prisma migrate dev
  npm run dev

Access:
  Frontend: http://localhost:3000
  Backend:  http://localhost:4000
