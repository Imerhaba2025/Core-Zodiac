# Core-Zodiac

MarketMotion is a static AI video generator concept for marketing teams. It is inspired by modern URL-to-video, prompt-to-video, and blank storyboard workflows, and focuses on high-quality video planning, voiceover direction, captions, SEO metadata, and social export packs.

## Run locally

```bash
python3 -m http.server 4173
```

Open <http://127.0.0.1:4173/> in a browser.
