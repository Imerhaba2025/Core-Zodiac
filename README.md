# Core-Zodiac

Core-Zodiac is my personal playground for crafting AI-powered tools, web apps, and mobile apps.

## Storm.dev-Inspired Build Prompt

You are an elite full-stack product squad tasked with cloning the immersive polish of https://storm.dev/ while amplifying every facet of design, layout, and technology to match my personal "vibe coding" aesthetic.

**Mission**
- Produce a lightning-fast, responsive experience that feels like a futuristic command center for building AI tools, web apps, and mobile apps.
- Fuse the cinematic storytelling and kinetic motion of Storm.dev with the playful craftsmanship of https://lovable.dev/, the crisp productivity flow of https://app.base44.com/, the cinematic AI showcase of https://famous.ai/, and the modular builder feel of https://v0.app/.
- Deliver a seamless ecosystem that I can host on Hostinger, leveraging ChatGPT-powered copilots, Ideogram.ai for signature imagery, Canva for quick design tweaks, and Gamma.app for pitch-ready landing pages and proposals.

**Design & Layout Directives**
- Layout should embrace dark-mode luxury with neon accents, layered glassmorphism, and animated gradients reminiscent of Storm.dev, but tuned to my personal brand.
- Use bold typography pairings (wide display headers + humanist body fonts) with fluid typographic scaling and immaculate vertical rhythm.
- Craft a modular component system with hero moments, portfolio case studies, product launch pads, and AI lab dashboards. Motion should be purposeful: parallax reveals, magnetic cursor interactions, scroll-triggered storytelling.

**Technology & Experience Goals**
- Build with a modern Jamstack approach (Next.js/React, server components where beneficial, edge deployment friendly). Prioritize high Lighthouse scores, instant page transitions, and global CDN readiness for Hostinger deployment.
- Integrate AI-first workflows: conversational build assistant panels powered by ChatGPT, Ideogram.ai hooks for instant concept art, Canva one-click export zones, and Gamma.app sharing flows.
- Support responsive breakpoints from large displays to mobile with adaptive gestures, haptic-ready interactions, and polished micro-animations on touch devices.
- Provide theming controls so I can toggle between "focus", "creative", and "launch" modes, each updating color schemes, lighting, and dashboard widgets.

**Content & Narrative**
- Showcase signature projects (AI copilots, automation suites, data dashboards) with immersive storytelling: challenge, approach, tech stack, outcome.
- Highlight toolchain integrations (ChatGPT, Ideogram.ai, Canva, Gamma.app) as glowing capability cards with interactive demos.
- Include call-to-actions for collaboration, consultations, and live demos. Embed calendar scheduling and contact flows with frictionless forms.

**Delivery Checklist**
- Provide polished Figma (or equivalent) mockups, component library documentation, and production-ready code repo.
- Include deployment instructions tailored to Hostinger, with CI/CD guidance and environment variable templates.
- Ship branded image assets, Ideogram.ai prompt library, Canva templates, and Gamma.app landing page copy scripts.

Craft the experience as if it were the flagship hub of a visionary creator, capturing the energy of Storm.dev and elevating it into my personal Core-Zodiac universe.
